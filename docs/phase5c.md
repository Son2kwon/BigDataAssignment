## 5c.1 설계·구현 (2026-11-15, 학습 실행 전)

### 한 일

- `afp/features.py`에 5c 피처 `trend_features`를 더했다. 기존 함수(`m1_features`, `step_values`, `window_features`)는 바꾸지 않았다
  - 대상은 5b 창 피처 7개의 스텝 단위 계열이다 (`TREND_SERIES`: `is_error`, `edit_failed`, 성공 편집, `repeat_prev`, `repeat_any`, 새 파일, `obs_len`). 새 파일 계열은 `window_features`와 같은 정의("이 스텝에서 그 파일을 처음 열었다")라서, 이전 구간 값은 창 시작 전에 처음 연 파일 수다 (P5c-D3)
  - 창 = 스텝 N−k+1..N, 이전 구간 = 스텝 1..N−k. k 집합은 S1을 따라 {3}이다 (P5c-D1)
  - (a) 가중합 `{base}_a{α}_w3` = 이전 + α×창, α ∈ {2, 4, 8}. `obs_len`은 (이전 합 + α×창 합) / ((N−k) + α·k)
  - (c) 변화율 `{base}_chg_w3` = 창/k − 이전/(N−k). `obs_len`은 창 평균 − 이전 평균 (같은 식이다)
  - (b) 지수 감쇠 `{base}_g{05|07|09}` = Σ_{t≤N} γ^(N−t)·x_t, γ ∈ {0.5, 0.7, 0.9}. 창과 무관해서 N=3에도 있다. `obs_len`은 가중 **합**이라 이름을 `obs_len_sum_g*`로 했다 (사전 등록의 식 그대로. 같은 N 안에서는 가중 평균과 상수배 차이뿐이다)
  - 기울기 `obs_len_slope_w{k}` = 창 안 `obs_len`을 스텝 번호에 OLS로 맞춘 기울기, k ∈ {3, 5} (P5c-D4·D8). 닫힌 식 Σ(t − t̄)·y / Σ(t − t̄)²로 계산한다
  - k ≥ N이면 (a)·(c)·기울기 열을 만들지 않는다 (N=3: 감쇠만, N=5: 기울기 k=3까지)
- `code/04f_m1_trend.py`: 5b 스크립트(`04e_m1_window.py`)의 설계 행렬·장치·OOF·운영점·부트스트랩 함수를 import해서 그대로 쓴다. 5c에만 있는 것은 두 단계 선택과 S1 확인이다
  - 1단계: 묶음 1~6과 α·γ 후보 = 변형 10개 (s1, a2, a4, a8, chg, g05, g07, g09, sl5, sl35) × 모델 2개 × N 6개를 학습한다. α\*·γ\*, 7번 묶음의 두 조각(2와 3 중 하나, 5와 6 중 하나)을 고른다
  - 2단계: 7번 묶음(combo)을 학습한다
  - 최종 묶음 7개 (1 s1 / 2 a{α\*} / 3 chg / 4 g{γ\*} / 5 sl5 / 6 sl35 / 7 combo)로 운영점(손실 ≤3.5%, 단독·결합), 부트스트랩 구간(S1 대비 짝지은 차이), S2 선택, 가설 확인(P5c-D7)을 한다
  - 같은 (모델, N, 열)은 한 번만 학습한다. N=3에서는 a·chg·sl5·sl35가 S1과 같고, N=5에서는 sl5가 S1과 같다. 설계 수는 1단계 106개 + 2단계 최대 8개다
  - 묶음 피처 수 (N ≥ 8): S1 80 / 2·3·4 87 / 5 81 / 6 82 / 7 88 또는 89. N=5: 2·3·4 87, 5 = S1 80, 6 81. N=3: 4만 80, 나머지 73
  - 시작할 때 `results/phase5b/summary.json`의 S1이 `w3`(창 k=3)인지 확인하고, 아니면 멈춘다 (S1을 코드에 고정했기 때문. PLAN P9-D2 (2))
  - `--smoke`: train 이슈 1/10, 그리드 앞 2개, 부트스트랩 20회. `data/processed/phase5c_smoke/`에만 쓴다
- 테스트 `code/tests/test_features_trend.py` (12개, PLAN "5c: 테스트는 5b와 같다"):
  - 손 계산: 5b 테스트의 8스텝 궤적으로 (a)·(b)·(c)·기울기 값
  - 기울기가 `numpy.polyfit`와 같다
  - 항등식: (a)·(c)의 창 값이 5b 창 피처와, 이전 값이 "M1 합계 − 창"과 맞다. 새 파일은 이전 + 창 = 열어 본 고유 파일 수
  - ① 스텝 N 이후를 바꾸기·지우기·덧붙이기, 행 섞기, 궤적 길이 늘리기에도 값이 같다
  - ② k ≥ N이면 그 k의 열이 없다 (감쇠는 N=3에도 있음)
  - ③ 창 경계 (스텝 N−k → 이전, N−k+1 → 창). 스텝 N−k의 관측 길이를 바꿔도 창 k 기울기가 같다
  - ④ 사건이 없으면 횟수 계열이 모두 0, 관측 길이가 일정하면 변화율·기울기가 0
  - ⑤ `check_features` 통과 (없어야 할 열을 요구하면 결측으로 걸림)
